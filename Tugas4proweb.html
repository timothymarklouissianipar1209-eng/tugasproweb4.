Dasar Pemrograman Web

HTML

HTML digunakan untuk membuat struktur dasar halaman web, seperti judul, paragraf, gambar, tombol, dan elemen utama website.

CSS

CSS digunakan untuk mengatur tampilan halaman web, seperti warna, ukuran tulisan, jarak, posisi, dan tata letak website.

Bootstrap

Bootstrap adalah framework CSS dengan komponen siap pakai untuk membuat website lebih cepat, rapi, dan responsif.
